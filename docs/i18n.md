# 国际化（i18n）

## 1. 机制总览

```
Config.options.language.ui ──┐
                             ├─→ Translation.languageCode ─→ TranslationReader
Qt.locale().name ────────────┘         （单例）                读 translations/<code>.json
                                                                     │
QML 里 Translation.tr("English key") ←───────────────────────────────┘
```

- **key 就是英文原文**，value 是译文。`translations/en_US.json` 是 identity 映射（英文→英文），
  作为「基准语言」，其它语言相对它算缺口。
- 运行时按 `languageCode` 读 `translations/<code>.json`（以及用户目录下的
  `~/.config/quickshell/end4-pC/translations/<code>.json` 覆盖层）。
- **缺失的 key 回退成 key 本身**（也就是显示英文），不会报错、不会留空 ——
  见 `services/Translation.qml` 的 `tr()`。
- 代码里一律写 `Translation.tr("Some English text")`，**不要**写裸字符串。

## 2. 切换语言

设置 → **General** → 语言下拉框（`modules/ii/settings/pages/GeneralConfig.qml`）。

- 选项来自 `Translation.allAvailableLanguages`，即 `translations/` 目录下扫描到的语言码
- `auto`（默认）跟随系统 locale（`Qt.locale().name`）
- 写入 `Config.options.language.ui`，改完立即生效（`onLanguageCodeChanged` 会 reread 文件）

命令行改：

```bash
python3 - <<'PY'
import json
p = "/home/xibie/.config/illogical-impulse/config.json"
d = json.load(open(p, encoding="utf-8"))
d.setdefault("language", {})["ui"] = "zh_CN"   # 或 "auto"
json.dump(d, open(p, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
PY
```

改完不用重启 quickshell，文件被 reread 后界面即时更新。

## 4. 扩展新语言

1. 复制基准文件：

   ```bash
   cd ~/.config/quickshell/end4-pC/translations
   cp en_US.json <新语言码>.json        # 语言码形如 pt_PT / ko_KR / nl_NL
   ```

2. 逐条把 value 翻成目标语言（key 不动）。只想先跑起来也可以留英文，
   缺失/未翻的条目会自动回退显示英文。

3. **不需要注册**：`TranslationScanner` 启动时扫 `translations/` 目录，
   新文件会被自动发现并出现在设置的语言下拉框里。重启一次 quickshell 即可。

4. 校验 JSON 合法：

   ```bash
   python3 -c "import json;json.load(open('translations/<新语言码>.json',encoding='utf-8'))"
   ```

## 5. 新增文案的正确姿势

1. QML 里写 `Translation.tr("English text")`，别写裸字符串。
2. 跑一遍缺口检查（见下），确认新 key 在哪些语言里缺。
3. 补进对应的 `translations/<code>.json`。

**文件必须按 key 的码点排序**（仓库现状如此）。按序合并只会产生「插入若干行」的
干净 diff；重排整个文件会产生上千行噪音。

`placeholderText:` 等属性上的裸字符串。用一个简单的静态扫描就能找出来：


> 例外：`PNG · JPG · WEBP · AVIF · BMP · PDF · TIFF` 这类格式缩写是语言中立的，

## 9. 数字与日期格式

- **日期/时间**：走 `Qt.locale()`，例如仪表盘用
  `Qt.locale().toString(DateTime.clock.date, "yyyy/MM/dd")`、
  `Qt.locale().toString(date, "dddd")`（星期几自动按当前 locale 出词）、
  `Qt.locale().toString(date, "ap")`（12 小时制的 AM/PM）。
  **不要**自己拼 `"周" + n` 这种字符串。
- **相对时间**（今天/昨天/N 天前）：`GitHub.relativeDate()` 把数字和单位拆开，
  单位词过 `Translation.tr`（`today` / `yesterday` / `days ago` / `months ago` /
  `years ago`），数字部分保持数字。
- **数字对齐**：等宽数字用 `font.features: { "tnum": 1 }`，与语言无关。
- **百分比/单位**：`%` 直接拼在数字后（各语言一致）；物理单位（`hPa` / `m/s` / `km`）
  保持国际单位符号，不翻译。
