# Neovim 快捷键速查表

这套配置是 **LazyVim + 一层「现代快捷键」**。取舍原则只有一条：

> **不是 vim 动词的键保留（存盘、找文件、移动行、注释），
> vim 动词（复制/粘贴/撤销/删除）还给 vim 自己。**

所以下面「已拆掉的键」那一节是最重要的——它告诉你原来靠 Ctrl 干的事，现在该按什么。

配置本体在 `dot_config/nvim/`（`lua/config/keymaps.lua` 是 Ctrl 系，`lazyvim.json` 管 extras）。

---

## 一、保留的现代快捷键

| 键 | 作用 | 等价的 leader 键 |
|---|---|---|
| `Ctrl+S` | 保存（所有模式下都有效） | — |
| `Ctrl+P` | 找文件 | `<leader>ff` |
| `Ctrl+F` | 搜当前文件内容 | `<leader>sb` |
| `Ctrl+B` | 文件树开关 | `<leader>e` |
| ``Ctrl+` `` | 终端开关 | `<leader>ft` |
| `Ctrl+/` | 注释当前行（插入模式下也能用） | `gcc` |
| `Alt+j` / `Alt+k` | 把当前行向下/向上移动 | — |
| `Ctrl+←` / `Ctrl+→` | 插入模式下按词左右跳 | — |
| `Ctrl+C`（插入模式） | 等同 `Esc`，且会触发切回英文输入法 | — |

> `Ctrl+P/F/B/`` 和对应的 leader 键**指向同一个工具**（Telescope / Neo-tree / snacks 终端），
> 不是两套实现。用哪个都行，随学习进度自然漂移。

## 二、已拆掉的键 → 现在请按这些

这是这套配置和「VS Code 习惯」最大的差别，也是要学的东西。

| 原来按 | 现在按 | 说明 |
|---|---|---|
| `Ctrl+Z` | `u` | 撤销 |
| `Ctrl+Y` | `Ctrl+r` | 重做 |
| `Ctrl+A` | `ggVG` | 全选（`gg` 到文件头，`V` 选整行，`G` 到文件尾） |
| `Ctrl+C` | `y` | 复制。已开 `clipboard=unnamedplus`，`y` 直接进系统剪贴板，粘到浏览器没问题 |
| `Ctrl+X` | `d` | 剪切 / 删除 |
| `Ctrl+V` | `p` | 粘贴 |

拆掉之后有几个键回归了 vim 原生含义，**是意外收获**：

- `Ctrl+V`（normal 模式）→ 块选择模式（竖着选一列）
- `Ctrl+A`（normal 模式）→ 把光标下的数字 +1
- `Ctrl+X`（normal 模式）→ 把光标下的数字 -1

⚠️ **`Ctrl+Z` 现在会挂起 nvim**（vim 原生行为，`:suspend`）。你会回到 shell，输入 `fg` 可以恢复。
别慌，这不是崩溃。撤销是 `u`。

如果这个挂起太烦，在 `lua/config/keymaps.lua` 里加一行就能关掉：

```lua
map("n", "<C-z>", "<Nop>", { desc = "Disabled (use u)" })
```

## 三、vim 原生动作（分阶段）

### 第 1 阶段：先能活下来

| 键 | 作用 |
|---|---|
| `i` | 进插入模式（光标前） |
| `a` | 进插入模式（光标后） |
| `Esc` | 回 normal 模式（**最重要的一键**） |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:q!` | 不保存强退 |
| `h` `j` `k` `l` | 左 下 上 右 |
| `u` | 撤销 |
| `x` | 删一个字符 |

### 第 2 阶段：开始有效率

| 键 | 作用 |
|---|---|
| `w` `b` `e` | 按词往后 / 往前 / 到词尾跳 |
| `0` `^` `$` | 行首 / 第一个非空字符 / 行尾 |
| `gg` `G` | 文件开头 / 结尾 |
| `Ctrl+d` `Ctrl+u` | 向下 / 向上翻半页 |
| `dd` `yy` `p` `P` | 删整行 / 复制整行 / 粘到后面 / 粘到前面 |
| `dw` `cw` `ciw` | 删一个词 / 改一个词 / 改光标所在的整个词 |
| `/` `n` `N` | 搜索 / 下一个 / 上一个 |
| `v` `V` | 字符级可视选择 / 整行可视选择 |

### 第 3 阶段：组合技

| 键 | 作用 |
|---|---|
| `ci"` `ci(` | 改引号内 / 括号内的内容（不用先选中） |
| `da"` `di(` | 连引号一起删 / 只删括号内 |
| `.` | 重复上一次修改（威力极大） |
| `%` | 跳到匹配的括号 |
| `f{字符}` `t{字符}` | 本行内跳到 / 跳到前一个该字符处 |
| `Ctrl+o` `Ctrl+i` | 跳转历史后退 / 前进 |
| `gcc` | 注释当前行（`gc` 是 nvim 内置操作符） |
| `>>` `<<` | 缩进 / 反缩进 |
| `q{寄存器}` … `q` / `@{寄存器}` | 录制宏 / 播放宏 |

## 四、LazyVim 的 leader 键（`<leader>` = 空格）

### 文件与查找

| 键 | 作用 |
|---|---|
| `<leader>ff` | 找文件（项目根） |
| `<leader>fr` | 最近打开的文件 |
| `<leader>fb` | 已打开的 buffer 列表 |
| `<leader>e` | 文件树 |
| `<leader>/` | 全项目全局搜索 |
| `<leader>sg` | 全项目全局搜索 |
| `<leader>sb` | 当前文件内搜索 |
| `<leader>sw` | 搜光标下的词 / 选中的内容 |
| `<leader>sr` | 多文件搜索替换（grug-far） |

### buffer 与窗口

| 键 | 作用 |
|---|---|
| `Shift+h` / `Shift+l` | 上一个 / 下一个 buffer |
| `<leader>bd` | 关闭当前 buffer |
| `Ctrl+h/j/k/l` | 在窗口之间移动 |
| `<leader>-` / `<leader>\|` | 水平 / 垂直分屏 |
| `<leader>wd` | 关闭当前窗口 |

### LSP（代码跳转与修改）

| 键 | 作用 |
|---|---|
| `gd` | 跳到定义 |
| `gr` | 引用列表 |
| `K` | 悬停文档 |
| `<leader>ca` | 代码动作（快速修复） |
| `<leader>cr` | 重命名符号 |
| `<leader>cd` | 当前行诊断浮窗 |
| `]d` / `[d` | 下一条 / 上一条诊断 |

### Git

| 键 | 作用 |
|---|---|
| `]h` / `[h` | 下一个 / 上一个改动块 |
| `<leader>ghs` | 暂存当前改动块 |
| `<leader>ghr` | 还原当前改动块 |
| `<leader>gb` | 当前行 blame |
| `<leader>gg` | 打开 lazygit（**需要装 lazygit**） |

### 其他常用

| 键 | 作用 |
|---|---|
| `<leader>?` | **弹出完整键位菜单**（which-key） |
| `<leader>sk` | 模糊搜索所有键位 |
| `<leader>l` | Lazy（插件管理器） |
| `<leader>qs` | 恢复上次的会话 |
| `<leader>ur` | 重绘 / 清掉搜索高亮 |
| `<leader>us` | 开关拼写检查 |

## 五、忘了键位怎么办

1. **按 `<leader>`（空格）停 0.2 秒** → which-key 弹出这个前缀下所有可用的键。
2. **`<leader>?`** → 弹出完整键位菜单（buffer 相关）。
3. **`<leader>sk`** → 模糊搜索所有键位。
4. `:Telescope keymaps` → 同上。

不要背。用哪个查哪个，查十次自然记住。

## 六、已知问题

- **``Ctrl+` `` 可能送不出来**：部分终端不区分 `Ctrl+`` ` 和单独的反引号。如果按了没反应，
  用 `<leader>ft` 开终端。要换键的话改 `lua/config/keymaps.lua`。
- **文件树/搜索第一次打开会慢一拍**：Neo-tree、Telescope 是懒加载的，第一次调用才载入。
