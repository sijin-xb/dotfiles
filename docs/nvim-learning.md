# Neovim 学习清单

这是一份**打勾用的清单，不是教程**。别通读，按周练。

环境已经替你铺好了：模式光标会变色、输入法会自动中英切换、which-key 会在你按下空格后
弹出可用键位、速查表在 [nvim-keymaps.md](nvim-keymaps.md)。

---

## 第 1 周：先活下来

目标：**不用鼠标和方向键，能改一个文件并保存。**

- [ ] 走一遍中文教程：终端里敲 `vimtutor zh_cn`（约 30 分钟）
      - 如果那个命令没反应，直接练这个副本：
        `cp /usr/share/vim/vim92/tutor/tutor1.zh_cn /tmp/vt && nvim /tmp/vt`
- [ ] 学会这 6 个，别的先不管：`i`、`Esc`、`:w`、`:q`、`h j k l`、`u`
- [ ] 每天拿一个真实文件练手（改 dotfiles 里的任意配置最安全）

**验收**：把一个配置文件里的某行改掉、保存、退出，全程没碰鼠标。

---

## 第 2 周：开始有效率

- [ ] 词级移动：`w` `b` `e`，行首行尾 `0` `$`
- [ ] 整行操作：`dd` `yy` `p` `P`
- [ ] 改一个词：`ciw`（不用先选中）
- [ ] 搜索：`/` 然后 `n` `N`
- [ ] 大范围跳：`gg` `G` `Ctrl+d` `Ctrl+u`
- [ ] 可视选择：`v`（字符级）`V`（整行）

**验收**：把一个函数名从头改到尾，全程不碰鼠标。

---

## 第 3 周：组合技

- [ ] `.` 重复上一次修改 —— **这一周最值钱的一个键**
- [ ] 引号括号内操作：`ci"` `ci(` `da"` `di(`
- [ ] 行内跳转：`f{字符}` `t{字符}`，匹配括号 `%`
- [ ] 缩进 `>>` `<<`，注释 `gcc`
- [ ] 跳转历史：`Ctrl+o` 后退、`Ctrl+i` 前进

**验收**：改一段配置，其中用 `.` 重复了 5 次以上。

---

## 第 4 周：用上 leader 键（空格）

- [ ] `<leader>ff` 找文件、`<leader>sg` 全项目搜索、`<leader>e` 文件树
- [ ] LSP：`gd` 跳定义、`gr` 看引用、`K` 看文档、`<leader>cr` 重命名
- [ ] Git：`]h` / `[h` 跳改动块、`<leader>ghs` 暂存当前块
- [ ] 养成随手查的习惯：忘了就按 `<leader>?`

**验收**：在一次真实调试里，用 `gd` 跳进定义、再用 `<leader>cr` 改个名字。

---

## 拿你手上的东西练

| 练什么 | 用什么 | 为什么合适 |
|---|---|---|
| 纯编辑动作 | dotfiles 里的 niri / quickshell 配置 | 改坏了不影响系统运行，最安全 |
| LSP 跳转 | 音乐 API 那几个 JS/TS 项目 | 类型多、引用多，`gd`/`gr` 效果明显 |
| 诊断与修 | Rust（kugou-tui 之类） | `]d` `[d` 看诊断，`<leader>ca` 一键修 |
| 批量改 | Python 脚本 | `ciw` + `.` 批量改名很好练 |

---

## 每天 15 分钟就够

- **5 分钟**：挑一个动作，对着一个空文件重复 20 次（练肌肉记忆，不练思考）
- **10 分钟**：在真实文件里用它一次
- 不追求快，追求「不假思索」

---

## 常见坑

| 现象 | 原因 / 怎么办 |
|---|---|
| 打的字变成了命令 | 你在 normal 模式。看光标形状：方块 = normal，竖线 = insert。按 `i` 进插入模式 |
| 中文打不出来 | 插入模式会自动切回中文；如果没切，说明 `fcitx.nvim` 没生效，看 `:checkhealth` |
| 按 `Esc` 后输入法还是中文 | 同上。另外别用 `Ctrl+C` 代替 `Esc` 之外的方式退插入模式 |
| 按 `Ctrl+Z` nvim 消失了 | 那是 vim 原生的「挂起」，不是崩溃。回 shell 敲 `fg` 恢复。撤销用 `u` |
| 长行里 `j` 一次跳一整段 | vim 原生行为（按逻辑行移动）。想按屏幕行跳用 `gj` `gk` |
| 想保存 | `:w`，或者直接 `Ctrl+S` |
| 改完配置没生效 | nvim 里 `:source $MYVIMRC` 或重启；插件变更用 `<leader>l` |

---

## 出问题时

- `:checkhealth` —— 体检
- `<leader>l` —— 看插件状态、更新插件
- 配置本体在 `dot_config/nvim/`，速查表在 [nvim-keymaps.md](nvim-keymaps.md)

---

用一周之后，把「哪个键碍事」「哪个动作学不会」记下来。配置是按真实别扭点迭代的，
不是一次成型。
